# 2026-11-26

## EdgeOne Makers 部署适配与访问速度优化

- 研究确认：EdgeOne Pages 已升级为 EdgeOne Makers，原生支持 Next.js 13.5+/14/15/16 全栈（App Router、SSR、ISR、Route Handlers、proxy.ts、图片优化）；Next.js 级 rewrites/redirects 不支持，需在 edgeone.json 配置。构建默认 `npm run build` + 输出 `.next`，构建 Node 建议 22.11.0，云函数默认 Node v20。
- 新增 `edgeone.json`：固定 npm ci / next build / .next / node 22.11.0，云函数超时 60s；静态资源一年 immutable 缓存，图片与 /images 一天 + SWR，API 默认 no-store，仅 /api/app/version 缓存一小时；全局安全响应头。
- 移除 `package.json` 的 `postbuild`（构建期 db:migrate 会因无 DB 连接导致部署失败）；数据库迁移改为部署前一次性运维步骤，README 增加完整 EdgeOne 部署章节。
- `lib/base-url.ts`：构建阶段（NEXT_PHASE / npm_lifecycle_event）回退占位 URL，避免模块顶层在构建期因缺 BASE_URL 抛错；运行时仍强制要求 BASE_URL。
- `db/index.ts`：生产/开发均用 globalThis 复用 postgres.js 客户端，默认生产连接池 3（可用 POSTGRES_MAX_CONNECTIONS 覆盖），增加 idle/connect/max lifetime，降低 Serverless 连接耗尽风险。
- `proxy.ts`：收窄 matcher 跳过静态资源，兼容 x-forwarded-host / nextUrl.host 的 Origin 校验，避免 CDN 回源头导致写操作 403。
- `next.config.mjs`：加 GitHub 图片 remotePatterns、optimizePackageImports（lucide-react/date-fns）、关闭 X-Powered-By。
- Webhook 改为最多等待 8s + after() 混合处理，避免 Serverless 冻结丢失 GitHub 事件；两个 actions 路由加 maxDuration=30。
- `lib/token.ts` 支持单行 `\\n` 转义的 GitHub App PEM（适配 EdgeOne 单行环境变量）。
- 性能：新增 0013 迁移与 schema 快照，为 config / cache_file_meta 增加 `lower(owner),lower(repo),branch` 表达式索引；多组件头像/缩略图补 loading=\"lazy\" + decoding=\"async\"。
- 验证：`npm run build` 通过（无 BASE_URL 也通过）；`npm run lint` 0 errors（仅有既有 <img> 等 warnings）；`npx drizzle-kit check` 通过。

注意：本地构建未配置 BETTER_AUTH_SECRET 会出现 better-auth 默认 secret 警告，部署时必须设置该环境变量。Google Fonts 字体在构建期联网获取，EdgeOne 构建环境需能出网，否则后续可考虑改本地字体。
